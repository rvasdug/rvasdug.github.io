### Description
In November, 2024, Anthropic introduced the Model Context Protocol (MCP) to standardize how LLMs connect to services. Several months later, Google followed with the Agent2Agent (A2A) protocol to define how agents communicate with one another. Since then we've seen more emerging standards, such as Skills and Agent Client Protocol (ACP). You’ve likely heard of these protocols and standards, but how do they really work? What technologies power them? How is security enforced? What bindings exist across languages and frameworks?

Come to this session to peel back the curtain and see how it all works.
